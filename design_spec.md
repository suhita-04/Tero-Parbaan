# Brand Design Specification

Brand Name: Tero Parbon. Aesthetic: Classy, elegant, minimalist. Colors: Base backgrounds must be Beige/Cream (e.g., #FAF9F6). Accents and primary buttons must be a muted, elegant Red (e.g., #8B0000). Typography: High-end Serif for headings, clean Sans-Serif for body text. Layout: High whitespace, no heavy drop shadows, no cluttered borders.

## Detailed Guidelines

### 1. Brand Identity
- **Name:** Tero Parbon
- **Category:** High-end boutique ethnic fashion (Sarees, Kurtis, Blouses)
- **Aesthetic:** Classy, elegant, artisanal, minimalist luxury

### 2. Color Palette
- **Base Background:** Beige / Cream (`#FAF9F6`, `#F5F2EB`)
- **Primary / Accent:** Muted Elegant Red (`#8B0000`, Deep Crimson/Burgundy)
- **Neutral Dark (Text):** Deep Charcoal / Soft Black (`#1C1917`, `#2B2B2B`)
- **Border & Subtle Accents:** Warm Stone / Soft Gold (`#E7E2D7`, `#C5A880`)

### 3. Typography
- **Headings:** High-end Serif (e.g., `Playfair Display`, `Cormorant Garamond`, `Cinzel`)
- **Body Text:** Clean, legible Sans-Serif (e.g., `Plus Jakarta Sans`, `Inter`, `Montserrat`)

### 4. Layout & UI Principles
- **Whitespace:** Generous breathing room around collections, product cards, and editorial sections.
- **Shadows:** No heavy drop shadows; prefer subtle 1px border lines or soft ambient diffusion where needed.
- **Borders:** Crisp, minimal, and uncluttered.
